# Patch Diffing Workflow with Ghidra and BinDiff

### Setup

- Ghidra 11.0.3
- BinExport compatible with the Ghidra version.
- BinDiff.

### Description

Automated binary diffing pipeline using Ghidra headless analysis and BinExport for patch analysis.

## Directory Structure
```
project_root/
├── diffs/                          # Generated BinExport files and BinDiff results
│   ├── <PE_name>/
│   │   ├── patched_<PE_name>.BinExport
│   │   ├── unpatched_<PE_name>.BinExport
│   │   └── <bindiff output files>  # Generated by bindiff_run.ps1
├── patched/                        # Patched binaries
│   └── <PE_name>/
│       ├── <PE_name>.dll
│       └── <PE_name>.pdb           # Optional, auto-loaded if present
└── unpatched/                      # Original binaries
    └── <PE_name>/
        ├── <PE_name>.dll
        └── <PE_name>.pdb           # Optional, auto-loaded if present
```

## Prerequisites

- Ghidra 11.0.3+ installed at `C:\MyProgs\Ghidra\ghidra_11.0.3_PUBLIC\`
- BinExport extension installed in Ghidra
- BinDiff installed (default: `C:\Program Files\BinDiff\bin\bindiff.exe`)
- `binExport.py` script placed in `C:\MyProgs\Ghidra\Scripts\`
- PowerShell 5.0+

## Setup

1. **Install BinExport extension** in Ghidra GUI (File → Install Extensions)

2. **Place binaries** in the directory structure:
   - Patched binaries → `patched/<PE_name>/`
   - Unpatched binaries → `unpatched/<PE_name>/`
   - PDB files (optional) must match DLL/EXE name and be in same folder

3. **Create the Python export script** (`C:\MyProgs\Ghidra\Scripts\binExport.py`) . [`binExport.py`](./binExport.py)

## Usage

### Step 1: Generate BinExport Files

#### Single Binary Analysis
```powershell
C:\MyProgs\Ghidra\ghidra_11.0.3_PUBLIC\support\analyzeHeadless.bat `
  "C:\MyProgs\Ghidra\Projects\CVE-2026-20843" `
  "patched" `
  -import "C:\path\to\patched\RasMediaManager\RasMediaManager.dll" `
  -analysisTimeoutPerFile 300 `
  -scriptPath C:\MyProgs\Ghidra\Scripts `
  -postScript "binExport.py"
```

#### Batch Processing (Recommended)

Use the PowerShell wrapper script [`diff_bins.ps1`](./diff_bins.ps1):
```powershell
# Process all patched binaries
.\gen_binexports.ps1 "C:\Users\User\Desktop\optimal_dffing\patched" patched

# Process all unpatched binaries
.\gen_binexports.ps1 "C:\Users\User\Desktop\optimal_dffing\unpatched" unpatched
```

**Script parameters:**
- First argument: Full path to patched or unpatched directory
- Second argument: Type (`patched` or `unpatched`)

### Step 2: Generate BinDiff Comparisons

Use the PowerShell wrapper script [`bindiff_run.ps1`](./bindiff_run.ps1):
```powershell
# Generate BinDiff files for all BinExport pairs
.\bindiff_import_binexports.ps1 "C:\Users\User\Desktop\optimal_dffing\diffs"

# Custom BinDiff installation path
.\bindiff_import_binexports.ps1 "C:\Users\User\Desktop\optimal_dffing\diffs" -BinDiffPath "D:\Tools\BinDiff\bin\bindiff.exe"
```

**Script parameters:**
- First argument: Path to diffs directory
- `-BinDiffPath` (optional): Custom BinDiff executable location (default: `C:\Program Files\BinDiff\bin\bindiff.exe`)

**What it does:**
- Automatically finds all patched/unpatched BinExport pairs
- Runs BinDiff comparison for each pair
- Outputs results to the same directory as the BinExport files
- Provides success/failure summary

### Step 3: View Results in BinDiff GUI

Open the generated BinDiff files:
1. Launch BinDiff GUI
2. **File → Open Diff**
3. Navigate to `diffs/<PE_name>/` and open the `.BinDiff` file
4. View function matches, call graphs, and differences

Alternatively, create a workspace to organize multiple diffs:
1. **File → New Workspace**
2. **Import → Add Diffs** and select multiple `.BinDiff` files

## Output

After running all scripts, the structure will be:
```
diffs/
└── <PE_name>/
    ├── patched_<PE_name>.BinExport
    ├── unpatched_<PE_name>.BinExport
    └── <PE_name>.BinDiff              # BinDiff comparison results
```

## Workflow Summary

1. Organize binaries in `patched/` and `unpatched/` directories
2. Run `diff_bins.ps1` for both patched and unpatched sets
3. Ghidra analyzes each binary (imports, applies PDBs, runs analysis)
4. Python script exports to BinExport format in `diffs/<PE_name>/`
5. Run `bindiff_run.ps1` to generate BinDiff comparisons
6. Open `.BinDiff` files in BinDiff GUI to analyze differences

## Notes

- **PDB files**: Automatically loaded if they match the PE name and are in the same directory
- **Analysis timeout**: Default 300 seconds per file (adjustable in script)
- **Project separation**: Patched and unpatched binaries use separate Ghidra projects to avoid naming conflicts
- **Cross-platform**: Python script uses Java File APIs for Windows/Linux compatibility
- **Incomplete pairs**: `bindiff_run.ps1` will skip binaries missing either patched or unpatched BinExport files
